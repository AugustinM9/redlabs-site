# Redlabs — Site de présentation

Site vitrine en français pour le launcher Redlabs, qui réunit nos serveurs Minecraft et facilite le partage de nos modpacks et de nos maps.

## Aperçu local

Ouvrir `index.html` dans un navigateur. Aucun outil de compilation ni installation nécessaire.

## Contenu

- `index.html` : présentation et textes du site.
- `style.css` : styles adaptatifs mobile et ordinateur.
- `favicon.svg` : icône Redlabs.

Les illustrations sont réalisées en CSS. Les polices Google Fonts sont facultatives : le site utilise les polices système si elles ne sont pas accessibles.

## À personnaliser

Ajouter le lien officiel de téléchargement du launcher dans la section `#launcher` en remplaçant le message de disponibilité par un lien. Aucun téléchargement, adresse de serveur ou lien Discord n’a été inventé. Les blocs visuels sont des illustrations, pas des captures du launcher.

## GitHub Pages

Après envoi dans un dépôt GitHub, ouvrir **Settings → Pages**, choisir **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.

Le site n’utilise ni cookies, ni suivi, ni formulaire. Projet indépendant, non affilié à Mojang ou Microsoft.
